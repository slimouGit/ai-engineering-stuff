# Login-Probleme

Nach einem Softwareupdate können veraltete Browser-Cookies
zu Loginproblemen führen.

## Lösung

1. Browser-Cookies löschen.
2. Browser vollständig schließen.
3. Browser erneut öffnen.
4. Login erneut durchführen.

Falls das Problem weiterhin besteht,
soll ein Support-Ticket erstellt werden.
