# VPN-Probleme

Wenn keine VPN-Verbindung hergestellt werden kann,
sollte zuerst geprüft werden, ob eine normale
Internetverbindung vorhanden ist.

## Lösung

1. Internetverbindung prüfen.
2. VPN-Client schließen.
3. VPN-Client neu starten.
4. Zugangsdaten prüfen.
5. Verbindung erneut herstellen.

Falls weiterhin keine Verbindung möglich ist,
soll ein Support-Ticket erstellt werden.
