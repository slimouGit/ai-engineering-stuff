# Passwort-Probleme

Bei einem vergessenen Passwort kann die
Passwort-Reset-Funktion verwendet werden.

Nach mehreren fehlgeschlagenen Login-Versuchen
kann der Benutzeraccount gesperrt werden.

## Lösung

1. Passwort-Reset durchführen.
2. Neues Passwort vergeben.
3. Erneut anmelden.

Ist der Account gesperrt, muss der Support
kontaktiert werden.
